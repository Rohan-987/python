Python Notes 🐍

A collection of Python notes, examples, and practice programs created while learning and revising Python programming. This repository serves as a quick reference for programming fundamentals, problem-solving, and interview preparation.

📚 Topics Covered

Python Basics — Syntax, variables, data types, input/output, and type casting

Operators — Arithmetic, comparison, logical, assignment, and bitwise operators

Control Flow — if, elif, else, for, while, break, and continue

Data Structures — Lists, tuples, sets, and dictionaries

Strings — Indexing, slicing, string methods, and formatting

Functions — Parameters, arguments, return values, lambda functions, and recursion

Comprehensions — List, dictionary, and set comprehensions

Object-Oriented Programming — Classes, objects, inheritance, encapsulation, and polymorphism
